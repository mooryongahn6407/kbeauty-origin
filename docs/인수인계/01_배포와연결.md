- push 뒤 1~2분이면 라이브. 확인: 배포된 `assets/index-*.js` 안에 새 문자열이 있는지 curl로 본다.
- `netlify.toml`: 빌드 설정 + `manifest.webmanifest`를 `application/manifest+json`으로 내보내는 헤더.

## 서버 기능 (파트너 방문 집계)

| 무엇 | 파일 | 비고 |
|---|---|---|
| 방문 기록 | `netlify/functions/track-visit.mts` | POST. 파트너 코드로 «열기»·«결과 보기»를 셈(사람 수가 아니라 횟수) |
| 대표님 보고 | `netlify/functions/partner-report.mts` | `?key=` 필요. 화면은 https://app.korea-glow.com/?admin=report |
| 저장소 | Netlify Blobs `partner-visits` | 키 형식 `v1/<코드>/<yyyyMM>/<event>/<track>/<id>` (`src/app/partner-blob-keys.ts`) |
| 비밀 키 | Netlify 환경변수 `PARTNER_REPORT_KEY` | **저장소에 없음.** 값은 Netlify 사이트 설정 → Environment variables |

## SKIN QUEST (형제 앱)

- **https://play.korea-glow.com** — Netlify가 아니라 **Cloudflare**에서 나감. 순수 JS 정적 사이트:
  `index.html`, `css/app.css`, `js/{i18n,data,ing,engine,scenes,quiz,app}.js`, `manifest.json`, `icons/`.
- 이 클라우드 방이 볼 수 있는 GitHub 저장소에는 SKIN QUEST 소스가 **없음** → 그래서 이 방은 SKIN QUEST를
  못 고쳤음. 대표님 PC(또는 그 소스를 가진 방)에서는 고칠 수 있음.

## 두 앱 연결 약속 (주소 형식)

| 방향 | 주소 | 상태 |
|---|---|---|
| GLOW Class → SKIN QUEST | `https://play.korea-glow.com/?from=glowclass&p=<파트너코드>` | ✅ 첫 화면 카드 |
| SKIN QUEST → GLOW Class | `https://app.korea-glow.com/?from=skinquest&p=<파트너코드>` | ⬜ SKIN QUEST 쪽 버튼 필요 |

- GLOW Class는 `from=skinquest`를 보면 «SKIN QUEST에서 오셨네요!» 환영 문구를 띄움.
- 파트너 코드 형식·검사: `src/app/partner-shape.ts`. 코드는 폰에 기억되고 링크로 넘겨짐.

## 홈 화면 저장(설치)

- `public/manifest.webmanifest` + `public/icons/` (192·512·maskable·apple-touch). `index.html`에 연결.
- 안드로이드 크롬: 버튼 → 크롬 «설치» (탭 2번). 아이폰: «공유 → 홈 화면에 추가» 안내. 로직 `src/ui/install.ts`.
- **서비스 워커 없음(일부러).** 캐시하는 워커는 폰에 옛 화면을 붙잡아 둘 수 있음.
