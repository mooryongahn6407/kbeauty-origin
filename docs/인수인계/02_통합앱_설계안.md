# 02 · SKIN QUEST + GLOW Class 통합 설계안

대표님 목표: 놀이(SKIN QUEST)로 들어와서 공부(GLOW Class)로 이어지는 앱 — 폰에 저장해 두고 계속 보는 앱.

## 추천: 앱 하나, 아이콘 하나 (A안)

SKIN QUEST를 GLOW Class 안의 «게임 입구»로 옮긴다.

1. **엔진은 이미 있음.** GLOW Class의 얼굴 퀘스트(`src/app/care-quest.ts`, `src/content/care-quest/face-types.ts`,
   `face-concerns.ts`)에 세안 후 느낌·번들거림·모공 질문, 타입 5개, 고민 20개(진료 권유 표시 포함)가 다 있다.
   새로 필요한 건 **보여 주는 방식** — 10화면 속도감, 카드 뒤집기 결과 공개, «몰랐던 사실» 카드.
2. **«몰랐던 사실» 카드는 레슨에서만** 가져온다(`src/content/care-quest/lessons.ts`, 레슨 12개, 출처 포함).
   목록: `docs/기억/11_스킨퀘스트_개편안.md`.
3. 새 화면은 GLOW Class 안에 `?play`로 열리게 하고, **play.korea-glow.com은 `app.korea-glow.com/?play`로
   넘겨준다**(이미 뿌린 QR 코드가 계속 살아 있게). 매니페스트·아이콘은 하나로.
4. SKIN QUEST의 좋은 점(연꽃 브랜드, 남색 #0D1B3E, «실제 KOREA GLOW 제품 3개» 보여 주기)은 가져오되,
   제품은 **라벨·성분만** 보여 주고 효능을 약속하지 않는다(규칙 3·8).
5. 다 되면 SKIN QUEST 결과 → 해당 레슨으로 바로 가는 주소(`?lesson=<id>`)를 만든다.

## B안: 두 앱 그대로, 서로 링크

GLOW Class 쪽은 끝났다(01의 표). SKIN QUEST 쪽에 버튼 하나와 저장 버튼만 달면 된다(11 개편안 맨 위).
가장 빠르지만 아이콘이 두 개라 «하나의 앱»처럼 느껴지지는 않는다.

## 어느 쪽이든 지킬 것

- `CLAUDE.md` 16개 규칙과 773개 테스트. 새 화면에도 13px·44px·대비 AA·5개 언어·«초안» 표시.
- 진단·치료·전후 비교·지어낸 통계 금지. 진료 권유 표시는 재미 때문에 지우지 않는다.
