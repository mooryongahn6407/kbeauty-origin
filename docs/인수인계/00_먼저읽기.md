## 기술

React 18 + TypeScript + Vite · 테스트 Vitest(773개) · 서버 기능은 Netlify Functions(`netlify/functions/*.mts`)
+ Netlify Blobs · 원본 데이터는 엑셀(`sources/*.xlsx`) → `npm run extract:sources` → `data/source/*.json`.

```bash
npm install
npm run dev                 # http://127.0.0.1:5173
npm test                    # 773개 전부 통과해야 함
npm run typecheck
npm run build -- --base=/   # Netlify와 같은 빌드
```

## 반드시 지킬 것 (저장소 `CLAUDE.md`의 16개 규칙 요약 — 각 규칙마다 실패하는 테스트가 있음)

1. 원본 ID(`ING-001`, `QST-001` 등)는 절대 바꾸지 않는다.
2. Draft 자료를 «사실»처럼 말하지 않는다 — 지금 전문가 승인된 지식은 0건.
3. 성분·효능·안전 사실을 지어내지 않는다. 레슨은 전부 AAD·Cleveland Clinic 같은 공개 출처를 달고 씀.
4. 진단·치료 기능 금지. «치료/완치/cure/treat», 전후 비교, 지어낸 통계 금지.
5. 안전이 재미·판매보다 먼저.
6. 글씨 13px 이상, 누르는 곳 44px 이상, 밝은·어두운 모드 대비 AA, 색은 토큰으로만.
7. 검수 안 된 번역(라오어·태국어·프랑스어)은 화면에 «초안» 표시.
8. 공개 저장소에 가격·원가·수수료율·거래처·파트너 명단·개인정보·비밀번호를 넣지 않는다.
