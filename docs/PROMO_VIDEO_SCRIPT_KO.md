# KOREA GLOW SKIN QUEST — 홍보 영상 대본 및 콘티

**길이** 62초 · **화면비** 9:16 세로 (1080×1920) · **용도** 페이스북/틱톡/왓츠앱 공유, 파트너 모집 설명회
**제작 방식** 슬라이드 영화 — 정지 이미지 11장 + 자막 + 화면 전환. 촬영 없음, 성우 없음, 비용 0원.

---

## 기획 의도

**한 가지만 각인시킨다:** *"점수를 매기는 앱이 아니라, 읽는 법을 가르치는 앱."*

경쟁 앱들의 약점을 정면으로 건드린다. Yuka는 농도를 무시한 채 점수를 매겨 배합 전문가들에게 비판받고, OnSkin은 같은 제품에 49%와 67%를 준다. **소비자는 이미 앱의 숫자를 의심하기 시작했다.** 우리는 숫자를 주지 않는 대신 근거를 준다 — 그게 광고 문구가 아니라 실제로 앱이 하는 일이라는 점이 이 영상의 힘이다.

**금지 사항 (반드시 지킬 것)**
- 효능을 약속하지 않는다. "피부가 좋아집니다" 같은 문구 금지.
- 성분이 무엇을 한다고 말하지 않는다. 아직 검수 전이다.
- 진단처럼 들리게 하지 않는다. 의료 문구 금지.
- 경쟁사 실명을 자막에 쓰지 않는다 (내레이션 근거로만 사용).

## 제작 방법 (재현 가능)

1. **슬라이드 HTML을 만든다** — `scripts/promo/slides.html`. 컷 하나가 `<section class="slide">` 하나.
2. **Chromium으로 한 장씩 캡처한다** — 1080×1920, 배율 1.
3. **ffmpeg로 붙인다** — 컷별 지속 시간대로 이어 붙이고, 컷 사이에 0.4초 디졸브.
4. **자막은 이미지에 구워 넣는다** — 별도 자막 파일 없이 어디서나 그대로 보이게. 언어별로 같은 방식으로 다시 뽑으면 라오어·영어판이 나온다.

```bash
npm run promo:video      # 슬라이드 캡처 → mp4 생성
```

**비용** 0원. AI 이미지 생성도, 성우도, 촬영도 쓰지 않는다. 앱 화면과 글씨만으로 만든다.

## 언어별 버전

같은 컷 구성으로 자막만 바꿔 3종을 뽑는다.

| 버전 | 용도 |
|---|---|
| 한국어 | 본사 보고, 한국 파트너 |
| **ລາວ (라오어)** | **현지 소비자 — 최우선** |
| English | 브랜드 입점 제안, 투자자 |

라오어판이 가장 중요하다. 라오스 소비자를 대상으로 라오어 홍보 영상을 내보내는 한국 화장품 회사는 사실상 없다.

## 이 영상이 구독을 만드는 지점

영상이 팔려는 것은 화장품이 아니라 **"나는 속지 않는다"는 느낌**이다.

- 1–2컷: *나도 저런 적 있다* (공감)
- 4컷: *맞아, 그 점수 뭘 믿고 보는 거지?* (불신의 언어화)
- 5컷: *이 앱은 다르다고 하네* (차별점)
- 6–8컷: *진짜로 다르네* (증명 — 말이 아니라 화면으로)
- 9컷: *내 말로 되네* (소속감)
- 10–11컷: *4분이면 되고 선물도 준대* (낮은 진입장벽 + 보상)

마지막 컷까지 **효능을 한 번도 약속하지 않는다.** 그래서 믿긴다.
