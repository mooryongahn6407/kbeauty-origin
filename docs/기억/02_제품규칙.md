# 02 · 제품 규칙 — 왜 이 앱은 아무 말이나 하지 않는가

원문은 저장소 루트 `CLAUDE.md`에 영어로 있습니다. **코드에 손대기 전에 그것을
읽으십시오.** 이 파일은 그 규칙들이 *왜* 있는지를 한국어로 풀어 쓴 것입니다.

## 한 문장 요약

> 마스터 데이터베이스에 있는 것 중 **승인(Approved) + 근거 검증(Verified)** 을
> 통과한 것만 "사실"로 말할 수 있다. 오늘 그것을 통과한 것은
> **루틴 10건뿐**이다. 나머지는 전부 초안(Draft)이다.

그래서 앱은 "이 성분은 보습에 좋습니다"라고 **말할 수 없습니다.**
대신 "데이터베이스가 이 성분을 Humectant 계열로 분류한다"고 말합니다.
그것은 사실이고, 확인 가능하고, 지어낸 것이 아닙니다.

## 규칙 16개 (요약)

1. **소스 ID를 바꾸지 마라.** `D01`, `ING-001`, `QST-001` 등은 그대로 쓴다.
2. **초안을 승인된 것처럼 다루지 마라.** `evaluatePublication()`만 판단한다.
3. **과학·성분·제품·안전·규제 사실을 지어내지 마라.**
4. **없는 항목을 만들어 내지 마라.** 깨진 참조는 보고만 하고 고치지 않는다.
5. **58 vs 92 strand 문제를 임의로 해결하지 마라** (SR-001). 오너 결정 전까지
   `CANONICAL_TAXONOMY_ID = null`.
6. **안전 > 학습 > 참여 > 상업.** 그 다음 교육 > 상업.
   → 화면에서 선물 카드가 **맨 마지막**에 나오는 이유입니다.
7. **의학적 진단·치료 기능 금지.**
8. 과학·제품 주장을 UI 컴포넌트나 AI 프롬프트에 **하드코딩하지 마라.**
9. **숙달(mastery)과 상업적 지위를 분리하라.** 선물·인플루언서·파트너 등급이
   학습 기록을 건드리면 안 된다. XP 점수나 레벨 기준값은 **계산하지 않는다**
   — 어떤 출처도 그 숫자를 정의하지 않았기 때문 (OQ-X01).
10. 미해결 사항은 CONFIRMED / DECISION / HYPOTHESIS / IDEA / OPEN QUESTION /
    REJECTED 중 하나로 **분류해서 등록부에 남긴다.**
11. **AI 튜터는 문장을 생성하지 않는다.** `respond()`는 항상 `message: null`.
    헌장 §16 시나리오 10/10을 회귀 테스트로 지킨다.
12. **같은 숫자가 두 번 나오면 일치해야 한다.** 불일치는 경고로 올리고
    임의로 맞추지 않는다.
13. **가독성은 스타일이 아니라 강제 사항이다.** 13px 미만 금지 /
    밝은·어두운 모드 **둘 다** WCAG AA / 터치 44px / 포커스 표시 /
    컴포넌트는 색 이름을 직접 쓰지 않고 토큰만 쓴다 / 인라인 `fontSize` 금지.
14. **검수 안 된 번역은 초안이다.** `fr`·`lo`·`th`는 화면에 "미검수"라고 쓴다.
    사람만 이 상태를 바꿀 수 있다 — 커밋한다고 검수된 것이 아니다.
15. **음성이 문자 체계를 넘나들지 않는다.** 라오어 음성이 없는 기기에서는
    태국어 목소리로 **태국어 번역문**을 읽는다. 라오 글자를 태국 목소리에
    넘기지 않는다(소리가 깨진다). 그리고 **반드시 읽는 사람에게 알린다.**
16. **리듀서는 순수하다.** `(state, action)` 두 개만 받는다. 부수효과는
    `emitted`에 담아 `createDrainGuard()`가 한 번만 실행한다.

## 이 규칙들이 지켜지는 방식

말로만이 아닙니다. **각 규칙마다 깨지면 실패하는 테스트가 있습니다.**
2026-09-21 기준 테스트 578개, 파일 23개, 전부 통과.

예: `tests/design-system.test.ts`는 `src/ui/theme.css`를 직접 읽어서
색 대비를 W3C 공식으로 계산합니다. 눈대중이 아닙니다.
