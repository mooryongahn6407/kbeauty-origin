## 10화면 흐름

1. **히어로** — 루미나 노이(8/25 브랜드 공식 얼굴) 인사. 한 줄 훅: «세안하고 30분 뒤, 내 얼굴은
   어떤가요? 3분이면 내 피부 타입과 아침·저녁 순서를 알려 드려요.» 진행 표시 «10단계 · 약 3분».
   로그인 없음. 큰 시작 버튼 하나.
2. **세안 후 30분 느낌** — 전체가 당김 / 부분만 번들 / 전체가 번들 / 편안함
3. **오후 번들거림 위치** — 없음 / T존만 / 얼굴 전체
4. **모공이 보이는 정도** — 거의 안 보임 / 코 주변 / 볼까지
5. **예민함** — 새 제품에 따가움·붉어짐이 자주 / 가끔 / 거의 없음
6. **결과 ① 내 피부 타입 공개** — 카드 뒤집기 같은 짧은 연출. «왜 이 타입인지»를 내가 고른 답으로
   설명(2~5번 답 인용). 답이 섞이면 솔직하게 «복합성에 가까워요»처럼 확신 정도를 보여 준다.
7. **고민 고르기 (최대 3개)** — 4묶음: 트러블 / 톤·잡티 / 주름·탄력 / 건조·예민. 아이콘 + 짧은 이름.
   여드름·기미 등 기존의 «피부과 상담 권장» 표시는 그대로 둔다.
8. **생활 2문항** — 선크림을 매일 바르나요? / 하루에 바깥에 있는 시간은? (라오스의 강한 자외선)
9. **결과 ② 아침·저녁 순서** — 제품 «종류»만(브랜드 아님): 세안 → 토너 → 세럼 → 크림 → (아침)
   선크림. 고른 고민마다 «몰랐던 사실» 카드 1장 — 아래 목록에서만 고르고 출처를 표시한다.
10. **다음 단계** — 결과 카드 저장·공유. «왜 이 순서인지 더 알고 싶다면 → GLOW Class ‹바르는 순서› 레슨»,
    두피·헤어 / 바디 버튼. 파트너 코드(`?p=`)는 링크에 그대로 붙여 넘긴다.

## «몰랐던 사실» 카드 — 이 목록에서만 쓴다 (전부 GLOW Class 레슨에 출처가 있음)

| 사실 | 출처 (GLOW Class 레슨) |
|---|---|
| 자외선 A는 유리창을 통과하고, 구름 낀 날에도 상당 부분 내려온다 | AAD · Skin Cancer Foundation (선케어 더 알기) |
| 너무 자주·세게 씻으면 장벽이 약해져 오히려 건조·번들거림이 늘 수 있다 | AAD skin care basics (클렌징과 pH) |
| 피부 표면은 약산성(대략 pH 4~6, 보통 5 안팎) | Cleveland Clinic skin barrier (클렌징과 pH) |
| 크림 위에 세럼을 바르면 잘 스며들지 않는다 — 묽은 것에서 진한 것으로 | AAD (바르는 순서) |
| 비타민 C는 아침, 선크림 전에 — 몇 분 기다리면 선크림이 밀리지 않는다 | Cleveland Clinic vitamin C serum (바르는 순서) |
| 레티놀과 AHA·BHA는 같은 밤에 겹치지 않는다 | AAD exfoliation (성분 궁합) |
| 눈가 피부는 얼굴에서 가장 얇고 피지선이 적다 | Cleveland Clinic (아이크림) |
| 새 제품은 귀 뒤·팔 안쪽에 며칠(가능하면 7~10일) 먼저 발라 본다 | AAD test skin care products (패치 테스트) |

## 반드시 지킬 것

- 진단·치료 금지. 결과는 «타입»과 «관리 순서»까지. 질환 이름으로 사람을 판정하지 않는다.
- 치료·완치·cure·treat, 전후 비교 사진, 지어낸 통계(«80%가…») 금지.
- 위 목록에 없는 효능·사실을 새로 쓰지 않는다. 꼭 필요하면 공신력 있는 출처(AAD 등) 링크와 함께.
- 안전이 재미보다 먼저: 진료 권유 표시를 재미 때문에 지우지 않는다.
- 언어: 한국어·라오어·영어(+태국어·프랑스어). 사람이 검수하기 전의 번역은 «검수 전 초안» 표시.
- 가격·원가·수수료·거래처·파트너 명단은 화면·저장소 어디에도 넣지 않는다.
- 배운 정도(숙련도)를 파트너 등급·쿠폰·포인트와 섞지 않는다.
- 글씨 13px 이상, 누르는 곳 44px 이상, 밝은·어두운 모드 모두 대비 AA, 320px 폭에서 가로 넘침 0.
