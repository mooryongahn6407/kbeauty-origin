# 08 · 작업 환경 — 되는 것과 안 되는 것

이 방은 대표이사님 PC가 **아닙니다.** Anthropic 클라우드 컨테이너입니다.
이 차이 때문에 실제로 헛수고를 한 적이 있으므로 명확히 적어 둡니다.

## ❌ 안 되는 것

| 무엇 | 사실 |
|---|---|
| **대표이사님 PC 파일 접근** | `C:\Users\pc\Desktop\...` 는 **존재하지 않습니다.** `/mnt/c`도 없음(확인함). 그 경로에 뭔가 저장하라는 지시는 **파일을 보내드리고 직접 저장을 부탁**하는 수밖에 없습니다 |
| **외부 웹사이트 접속** | `WebFetch`·`curl`이 프록시에서 403으로 막힙니다. **라이브 앱 주소도 열 수 없습니다.** "가서 보고 분석해"가 불가능한 이유입니다 |
| **로컬호스트 = 대표이사님 PC 아님** | 이 방의 `127.0.0.1`은 이 컨테이너 안입니다 |
| **구글 드라이브의 사진** | 업로드하셔도 이 방으로 자동으로 오지 않습니다. 대화창에 직접 첨부해 주셔야 합니다 |
| **컨테이너 안의 파일** | 세션이 끝나면 사라집니다. **커밋하고 푸시한 것만 남습니다** |

## ✅ 되는 것

| 무엇 | 방법 |
|---|---|
| **웹 검색** | `WebSearch`는 작동합니다. 벤치마킹은 이걸로 했습니다 |
| **브라우저로 앱 직접 보기** | Chromium이 깔려 있습니다 — 아래 참조 |
| **npm 설치** | npm 레지스트리는 허용됩니다 |
| **GitHub 조작** | `gh` CLI는 없고, `mcp__github__*` 도구를 씁니다 |
| **Netlify 배포 상태 확인** | `mcp__Netlify__*` 도구 |
| **파일 전송** | `SendUserFile`로 대표이사님께 파일을 보낼 수 있습니다 |

## 앱을 브라우저로 직접 보는 법 (커밋 전 반드시)

```bash
npm run build -- --base=/     # ⚠️ --base=/ 없으면 빈 화면. 기본값은 /kbeauty-origin/
nohup npx vite preview --port 4241 --host 127.0.0.1 >/tmp/preview.log 2>&1 &
```

그 다음 저장소 루트에서(다른 데서는 모듈을 못 찾습니다) Playwright 스크립트 실행:

```js
import { chromium } from 'playwright-core';
const browser = await chromium.launch({
  executablePath: '/opt/pw-browsers/chromium-1194/chrome-linux/chrome',
});
const page = await browser.newPage({
  viewport: { width: 390, height: 780 }, deviceScaleFactor: 2, colorScheme: 'light',
});
page.on('pageerror', e => console.log('PAGEERROR', String(e)));   // ← 꼭 붙일 것
await page.goto('http://127.0.0.1:4241/', { waitUntil: 'networkidle' });
await page.screenshot({ path: '/tmp/shot.png' });
// 가로 넘침 검사
await page.evaluate(() => document.documentElement.scrollWidth - document.documentElement.clientWidth);
```

- 도구는 `--no-save`로 설치합니다 (`playwright-core`, `@ffmpeg-installer/ffmpeg`).
  `package.json`에 넣으면 모든 기여자와 CI가 이걸 받게 됩니다
- **헤드리스 Chromium에는 음성이 하나도 없습니다.** 음성 버튼이 "음성이 없습니다"로
  나오는 것은 정상입니다. 실제 폰에서는 다릅니다

## 배포 흐름

```
작업 브랜치에 푸시  →  라이브 안 바뀜
main에 머지         →  Netlify 자동 빌드 (약 30초~1분)  →  라이브 바뀜
```

`netlify.toml` → `command = "npm run build -- --base=/"`, `publish = "dist"`
