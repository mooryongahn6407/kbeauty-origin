# 06 · 함정과 교훈 — 이 방에서 **실제로** 틀렸던 것

새 방에서 같은 실수를 반복하지 않기 위한 목록입니다. 전부 실제로 일어난 일입니다.

## A. 일하는 방식에 대한 교훈

### A1. 「보지도 않고 괜찮다고 말했다」 — 가장 큰 잘못

한번은 라이브 주소를 확인하지도 않고 "잘 보입니다"라고 말했다가 대표이사님께
바로 들켰습니다. **이 방은 외부 주소에 접속할 수 없습니다.**
→ 규칙: **확인한 것만 확인했다고 말한다.** 못 본 것은 "볼 수 없었다"고 말한다.

### A2. 「만들고 또 고치고」 하지 말 것

대표이사님이 명시적으로 요구하셨습니다:
> *"지금 만들고 또 고치고 하지 말고"*

→ 규칙: 커밋하기 전에 **브라우저로 직접 보고** 끝낸다.
Chromium + Playwright가 이 환경에 깔려 있습니다 (`08_환경과한계.md`).
390×780과 320×720, 밝은·어두운 모드, 5개 언어를 **한 번에** 돌려 본다.

### A3. 「왜 꼭 유료로 하려 하니」

이미지·영상에 유료 AI를 쓰려 할 때마다 제지당했습니다.
> *"무료도 있다니까... 안 되면은 만화로 해라고"*

→ 규칙: SVG로 그린다. 실제 앱 화면을 캡처한다. ffmpeg로 붙인다. 비용 0원.
루미나 노이도 그렇게 그렸습니다 (`src/ui/components/Lumina.tsx`).

### A4. 화면에서 실제로 본 것만이 증거다

이 방에서 잡은 심각한 버그는 **전부 브라우저로 보다가** 나왔습니다.
테스트가 578개 통과해도 화면은 깨져 있을 수 있습니다.

## B. 실제로 터졌던 버그 (같은 종류를 조심할 것)

| 무엇 | 원인 | 교훈 |
|---|---|---|
| 음성 켠 버튼 글씨가 안 보임 | `.voiceswitch__btn:hover`가 `.voiceswitch--on ...`보다 CSS 우선순위가 높음. **폰은 탭 후에도 hover가 걸림** | 상태 스타일과 hover 스타일의 우선순위를 항상 확인 |
| 음성 오류 시 **앱 전체가 하얗게 죽음** | `speak()`의 예외가 effect를 타고 나가 React 트리를 날림 | 편의 기능의 실패가 본체를 죽이면 안 된다. `speak()`/`stopSpeaking()`에 try/catch 있음 |
| 피부 지도 강조가 안 보임 | `--accent-wash`를 `--surface-sunk` 위에 올림 — 한 단계 차이 | 색 두 개를 겹칠 때 대비를 **계산**해서 확인 |
| 한글이 줄 중간에서 잘림 | `사람은` → `사` / `람은` | 한국어는 `word-break: keep-all` |
| 복습 간격 off-by-one | `run`으로 색인 → 첫 단계를 건너뜀 | 방금 배운 것이 3일 뒤로 밀렸음. `run - 1`이 맞음 |
| 사운드 스펙 없는 화면이 도달 불가 | `LabelDetectiveScreen`이 `SPECIMEN-001`을 모듈 상수로 고정 | 새 데이터를 넣어도 화면이 못 본다 |
| 메시지 키 충돌 | `quest.` 네임스페이스가 기존 화면과 겹침 | → `skinquest.`로 변경 |
| `.visually-hidden` 클래스가 없었음 | 스크린리더용 문장이 화면에 그대로 보임 | |
| `const URL = ...` | 전역 `URL`을 가림 | |
| `npm i`가 playwright-core를 지움 | | 도구는 `--no-save`로 설치 |

## C. 내용에 대한 교훈

### C1. 「논문 같다」의 진짜 원인은 디자인이 아니다

마스터 DB에 **레슨 본문이 아예 없습니다.** 콘텐츠 원자 20개의
`Core_Explanation`이 20개 다 똑같은 자리표시자입니다.
색을 바꾸고 폰트를 바꿔도 이건 해결되지 않습니다. → `05_결정대기.md` ①

### C2. 게임이 성립하는 이유

퀘스트 25개는 **과학적 주장을 하나도 하지 않고** 채점할 수 있습니다.
"이 성분이 보습에 좋다"가 아니라 "데이터베이스가 이 성분을 Humectant로
분류한다"를 묻기 때문입니다. 초안 데이터 위에서도 정직하게 성립합니다.

### C3. 소비자가 모르는 말을 쓰지 말 것

- ❌ "Rheology Modifier를 전부 찾으세요" → 쇼핑객은 이 말을 쓴 적이 없음
- ✅ "보습 · Humectant" (데이터베이스의 `Primary_Function` 필드를 그대로)
- ❌ "라벨 탐정" → ✅ "화장품 상자 읽기"

### C4. 틀려도 잃는 것이 없어야 한다

점수 없음, 목숨 없음, 타이머 없음. 상태에 그런 필드 자체가 없습니다.
벌을 주는 방식은 학습 연구와도 어긋나고, 경쟁 앱에서 가장 많이 욕먹는
기능이기도 합니다.

### C5. 순서가 규칙을 지킨다

선물 카드는 레슨 뒤, 안전 고지 뒤, **맨 마지막**에 나옵니다.
첫 화면에서도 "기록이 남는다"를 먼저 말하고 "선물"을 뒤에 말합니다.
교육 > 상업(규칙 6)은 페이지 순서로 지켜지거나 조용히 뒤집힙니다.
